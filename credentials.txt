4. HOW TO RUN THE SYSTEM WITH PYTHON BACKEND
--------------------------------------------------------------------------------
Step 1: Open PowerShell or Command Prompt in the project folder:
        cd d:\MSEPROJECT\kevin

Step 2: Start the Python Backend Server:
        python server.py

Step 3: Open your web browser and navigate to:
        http://localhost:5000

The Python backend automatically:
- Serves all front-end interfaces on one port (5000)
- Exposes full REST APIs under /api/...
- Synchronizes with Supabase Cloud Database when connected
- Falls back to local persistent storage (data/database.json) with zero downtime
- Broadcasts real-time events across all connected browser tabs
